# Сборка материалов

## Лекции

Для лекции 1 используется XeLaTeX. Для лекций 2–4 используется pdfLaTeX.

Исходники используют HSE Beamer theme через строку:

```tex
\usepackage{HSE-theme/beamerthemeHSE}
```

Поэтому перед сборкой нужно разместить каталог `HSE-theme/` рядом с соответствующим `.tex`-файлом либо добавить путь к теме в `TEXINPUTS`.

Для лекций 2–4 сначала создайте каталог `figures/` и запустите:

```bash
python generate_figures.py
```

После этого собирайте слайды.

## Python-зависимости

Для скриптов генерации графиков достаточно стандартного научного стека:

```bash
pip install numpy matplotlib
```

Некоторые графики могут также использовать дополнительные пакеты, указанные непосредственно в соответствующем скрипте.
